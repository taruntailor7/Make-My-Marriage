# Make My Marriage — Landing Page Design

## Stitch Prompt

Below is the prompt to paste into Google Stitch. It includes every section,
color, typography, spacing, and content detail needed to generate the full
landing page design.

---

### PROMPT START

Design a full landing page for "Make My Marriage" — a modern SaaS product for planning Indian weddings. The page should feel like a premium productivity tool (think Linear, Notion, Vercel) with warm elegance — NOT like a traditional wedding invitation website. No pink, no red, no yellow, no floral decorations, no stock wedding photos, no rangoli, no diyas, no marigold garlands. This is a serious, trustworthy software product that happens to be for weddings.

**Brand identity:**
- Product name: Make My Marriage
- Tagline: "Your entire wedding. One place."
- Tone: Confident, premium, trustworthy, warm but professional

**Color palette (use exactly these):**
- Page background: #FAFAF8 (warm cream off-white)
- Card/surface backgrounds: #FFFFFF
- Primary text: #1A1A1A (rich charcoal black)
- Secondary text: #6B6B6B (warm medium gray)
- Accent color: #C8A26B (warm muted gold — use for buttons, highlights, icons, hover states)
- Secondary accent: #1E293B (deep navy — use for secondary buttons, badges)
- Dark section backgrounds: #111111 (rich near-black)
- Dark section text: #FAFAF8 (cream white on dark backgrounds)
- Borders/dividers: #E8E5E0 (warm light gray)

**Typography:**
- Hero heading and section headings: Playfair Display or Cormorant Garamond (serif), bold weight. Large size, letter-spacing slightly tightened.
- Subheadings and card titles: DM Sans or Inter (sans-serif), semibold weight.
- Body text and descriptions: DM Sans or Inter (sans-serif), regular weight.
- All text well-spaced and readable. Line height 1.5 for body, 1.2 for headings.

**Layout:**
- Max content width: 1200px, centered on page
- Generous padding between sections (80-120px vertical)
- 16px side gutters on mobile
- Clean grid-based layout, nothing overlapping or cluttered
- Every section has clear breathing room

**Design style:**
- Clean, minimal, generous white space
- Subtle rounded corners on cards (12-16px radius)
- Very subtle shadows on cards (not heavy drop shadows)
- No decorative illustrations or abstract shapes
- Subtle grain texture on the cream background (very faint, not noisy)
- Smooth section transitions — no harsh color jumps
- Icons: thin line-style, single-color (gold accent or charcoal), from a set like Lucide or Phosphor

## Dashboard Mockup — How to Build It

The hero and Section 6 both need a dashboard mockup. Two approaches:

### Option A: Build it in Stitch itself (Recommended)
Generate the landing page first with a placeholder rectangle where the
dashboard goes. Then create a second Stitch project:

**Stitch prompt for the dashboard mockup:**

> Design a SaaS dashboard screen for a wedding planning app called "Make My Marriage". Clean, minimal, modern UI on a cream/off-white background (#FAFAF8). Left sidebar (charcoal #1E293B) with navigation: Dashboard (active, gold accent), Events, Guests, Budget, Vendors, Invitations, Website, Settings. Top bar shows "Riya & Arjun's Wedding" with a dropdown wedding switcher. Main content area shows: (1) A countdown banner "48 days until your wedding" with a subtle gold gradient, (2) Four stat cards in a row: "6 Events" with calendar icon, "324 Guests" with users icon, "₹12,50,000 Budget" with wallet icon, "18 Tasks" with checklist icon — each card white with subtle border, gold icon, (3) Below: a horizontal scrollable row of event cards (Mehendi Dec 12, Sangeet Dec 13, Wedding Dec 14, Reception Dec 15) with colored dot indicators, (4) A task checklist section showing 4 tasks with checkboxes (2 checked, 2 pending). Typography: DM Sans. Colors: cream background, charcoal text, gold (#C8A26B) accents. No decorative elements, no floral, no wedding imagery. Clean SaaS aesthetic.

Export the dashboard as a PNG, then place it into the landing page design.

### Option B: Use a tool like Figma or Excalidraw
Faster for a rough version. Draw the dashboard layout with rectangles and
text. Good enough for a landing page mockup — it doesn't need to be pixel-
perfect, just recognizable as a real product.

### Option C: Build the real dashboard first
If you're going to implement Phase 1 soon anyway, building the real auth +
dashboard + events pages first gives you actual screenshots. Most authentic,
but delays the landing page.

**Recommendation:** Option A — generate both in Stitch. Landing page first
with a placeholder, dashboard mockup second, then composite them. The
dashboard mockup is the single most impactful element on the page.
